# v1.0 Stable Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v1.0 — a stable, production-ready Windows teleprompter with voice tracking, remote control, full documentation, and an automated release pipeline.

**Architecture:** Consolidates 8 wayfinder decisions (#15–#22) into execution. Work is organized in 4 phases: Quality & Testing → Remote Control → Documentation → Release. Each phase produces independently testable software.

**Tech Stack:** C++20 / Win32 / WebView2 / WASAPI / whisper.cpp, React 18 / TypeScript 5 / Vite 5 / Zustand, Vitest / Google Test / Playwright, CMake / WiX Toolset 4

**Spec:** Wayfinder Map #14 — all 8 decisions resolved. See `docs/whisper-model-selection.md` for model research.

## Global Constraints

- Windows-only for v1.0 (decision #16)
- Zero P0/P1 bugs at release (decision #15)
- CI green on every PR: frontend unit tests + E2E + C++ tests (decision #15)
- DE + EN only for v1.0 (decision #20)
- Multilingual `ggml-base.bin` as default Whisper model (decision #19)
- No auto-update, no code signing, no Microsoft Store for v1.0 (decisions #17, #18)
- GitHub Issues only for support (decision #15)
- Automated release pipeline: changelog + version bump + CI artifacts (decision #15)
- SemVer strictly enforced, 1-week feature freeze before release (decision #15)
- Performance targets: startup <3s, memory <200MB, voice latency <500ms (decision #15)
- 100% offline, no cloud dependencies

## Review Focus

1. **Voice tracking false pauses** — base model's ~20% German WER can cause mid-sentence pauses. Mitigation: pause hysteresis (future, not v1.0 blocker).
2. **Remote control security** — HTTP server must bind to local interface only, never 0.0.0.0. PIN code optional but recommended.
3. **WebView2 runtime missing** — already handled (#5), but verify error dialog appears on clean machines.
4. **Installer cleanliness** — uninstall must remove all files, registry entries, Start Menu shortcuts.
5. **Accessibility regressions** — ARIA labels must not break existing Playwright E2E tests.
